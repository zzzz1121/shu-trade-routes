# 独立角色立绘 · 0.4.15

阿禾、罗掌柜、许掌柜、沈娘子各有六张透明 PNG：`neutral` 普通、`smile` 微笑、`thinking` 思考、`puzzled` 疑惑、`worried` 担忧、`firm` 认真。

每位角色先以原有素材作为身份和画风参考重新生成一张基准图，再以基准图分别生成五张表情差分。全部使用内置 image_gen；完整提示词及生成来源见 `prompts.json`。这些是生成的游戏美术素材。

文件组织：`角色 ID/表情.png`。每张图只包含一个人物，2:3 透明画布，保留头顶和左右轮廓，身体延伸至大腿。立绘与地图行走小人独立，地图小人未替换。

`miniapp/ui/narrative.js` 根据人物和对白表情返回独立文件，未知表情回落普通表情。正式对白、章节开场、交易、提示和回看共同使用这组资源。人物舞台独立于对白框，长对白与选项不会改变人物尺寸；缩略头像可以局部取景，但不使用多人图集。

验收入口：`/web/portrait-review.html`。这里用于并排查看同一人物的六种表情，不是游戏剧情页面。
