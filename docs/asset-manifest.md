PNG 透明图优先作为平台交付格式，同时保存可编辑矢量源文件。主体保留约 10% 安全留白；不要在图标内写动态数量、价格、状态或路线。地图节点当前/可达状态由代码边框表现，通常无需额外状态图。

临时素材目录 assets/temporary/；正式素材目录 assets/final/。发布到小程序的资源另复制到 miniapp/assets/final/。当前不需要人物、大地图背景、文物照片、完整 UI 背景或大量插画。

接收正式资产时记录：作者、来源、授权范围、版本、交付日期、用途。未经授权不使用博物馆照片；若使用第三方开源图标，随资源保留原许可证。
