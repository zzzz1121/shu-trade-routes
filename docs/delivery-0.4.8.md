# 第一关 0.4.8 交付记录

本轮合并 V3.1 UI 与用户提供的 V4.0 第一关剧本。范围为第一关；第二至六关仅共用入口与组件适配，不修改交易条件、关卡难度或剧情。没有部署网站。

## 页面与组件

- 独立首页使用已确认的蜀地场景，主入口“启程”，副标题“钱有轻重，路有远近。”；重新载入回首页。
- 纵向章节旅程支持自然滚动，第一关大场景，后续关卡按编号显示状态；中途局面从该章节继续。
- 第一关紧凑 HUD 显示行动与负重；钱袋、情境对象、撤销、求助和账簿可达；任务、规则、章节、重试、声音进入菜单。
- 地图保留原比例和节点，道路上使用生成的四向玩家与阿禾图集，480ms 走动及 80ms 落点后才提交规则动作。阿禾沿同一路线稍后跟随。
- 对话使用底部半透明文字栏、独立名字与半身角色，逐条表情保持同一人物；玩家与旁白发言时保留上一位人物的倾听状态。继续、已读略过、选择、回看、声音可用。已读略过不替玩家选择或付款。
- 木匣、虚构旧票、货单、三种带标签布包、潮角以 CSS 近景或已有物品图作原型；没有引入外链图片。沈娘子增加同风格生成表情图集；守桥人与玩家不冒用别人的立绘。
- 成功提交才播放钱货入账与物品移动反馈。错误立即提示；简短地点气泡可收起。

文案策略：叙事采用原剧本，不新增人物关系；主界面只留当前目标、钱货和操作结果，完整规则放到委托/规则/账簿。后仓、前堂名称一致，不增加两者之间的捷径。

## 剧情与状态

S01 报到、S02 拾钱发现旧匣、S03 配款、S04 桥边或街巷、S05 后巷、S06 布铺、S07 认布与潮角、S08 付款、S09 核货交付记账、S10 旧票邀请及三种态度已接入。

旧票三种回应影响后续说话方式；后巷可问父亲记号与隐私，桥路线在结尾补齐线索。未在铺内展开检查时，回店增加核货入口；布在确认交付前仍属于玩家。错拿灰布/素布不扣款。结算按钮为“留在商行／重走一趟／返回首页”。

兑换草稿于“备好出发”原子提交；正式规则仍为仓库 8 铁钱、容量 5、兑换收 1、整批布价 6 重 2、至少付 2 铁钱、最多 4 步、每次进入收费桥收 1 铁钱。`engine.js` 与 `level.js` 未改。

货币选择同时受拥有量与订单余额限制，确认再次经过引擎。成功行动与有后果的剧情选择进入完整撤销栈；面板与草稿不占历史。已读记录独立。交付后的记账和结尾保存为待播事件，不提前结算，首次通关在结尾看完后才解锁第二关；正式结尾完成后重玩创建新会话。

第一关剧情局面存档为 version 2，与既有旧局面 version 1 区分；旧版中途记录提示重新开始，已解锁章节保留。缓存删除需确认，只移除本游戏四个键并重置内存与声音偏好。读写失败保留当前游玩能力并给出提示。

## 声音

三段背景音乐各 32 秒：`music-market.wav`、`music-old-note.wav`、`music-homecoming.wav`。按日常、木匣/旧票事件、交付后剧情切换。循环淡变，对话压低背景，首次手势解锁，后台暂停。独立音乐/环境/操作开关和音乐音量、总音量；总线提供各通道音量接口，设置可重试启用声音。

音频总计 24 个本地 WAV：3 配乐、3 环境层、18 行走/UI/钱货/系统/道具反馈。新增道具反馈复用本地纸张、木步和收货质感，不每句对白播放提示音。交互声冷却与四声部上限；小程序音频功能检测降级，循环音量逐步淡变。

音源全部为原创程序合成原型，无第三方采样与正式演奏录音。运行 `npm run sounds:build` 后再 `npm run music:build` 可再生成。资源映射集中于声音清单，后续正式配乐可直接替换文件与配置。
