## 关键边界

- 初始仓库8铁钱、随身0，兑换后出发检查拟装载重量。
- 非法金额、总额、币种、最低支付、错误地点、无桥费均不提交。
- 购买先扣钱再装货；出售先卸货再收钱；兑付严格限次、限额。
- 无解判断搜索实际可用命令，包括零步交易/交付，不以“步数已满”误杀可直接交付的状态。
- 二关先纯交子买药超重被拒；四关收交子走收费路、五关兑付不足判可恢复死局。
- 预览、取消、三级提示和重放剧情不修改资源或步数；非法操作不推进教学。
- 教学短卡不锁住实际操作；跳过教学与正常观看获得相同交易结果。
- 连续确认移动不会走两步；重复交易/重复交付不能领取奖励。
- 会话状态与命令返回结果均不泄漏内部可变引用；损坏或不可读进度可重新开局。

## 执行方式

```sh
node --test tests/*.test.js
node tests/fixed-screen.cjs
node tests/campaign-browser.cjs
node tests/terrain-extension.cjs
node scripts/build-web.js
```

浏览器检查使用Playwright1.62.1与Chrome；本机Node不在PATH，实际由Codex缓存的Node运行，Playwright通过NODE_PATH加载。普通环境安装Node和Playwright即可按README复现。
