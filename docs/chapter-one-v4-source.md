这是第一关从进入到结算的完整可实施剧本，包含主线、选项后果、场景探索、失败回应和重玩。未编写第二至第六关。它是写作与交互规格，不代表已接入项目或完成玩家测试。

## 一、改编约定

以《蜀地钱路_完整游戏策划文档_V2.0.md》第六节为规则基准，采用本次确认的新定位：地图与剧情同时呈现。人物、街区、交易数字与旧票事件为虚构；本文不作为宋代地理、服饰或交子实物复原依据。

此前试写里“沈娘子临时要求换许记交子”的情节取消，避免新增兑换任务和改变第一关付款条件。“青布两匹、素布一匹”改成抽象的一批布料，货物总价格和总重量保持原配置。旧交子的押记是虚构线索，不参与支付，不计资金。

### 1. 固定规则

| 项目 | 规格 |
|---|---|
| 仓库资产 | 铁钱8单位，尚未随身携带 |
| 初始兑换 | 投入整数X，2≤X≤8，得到X−1交子，固定手续费1；正式出发前可重新预览方案，只结算一次 |
| 出发后资产 | 铁钱8−X，交子X−1；不兑换时拟携铁钱8，因超重不能出发 |
| 负重上限 | 5格；每单位铁钱1格，交子0格 |
| 布料 | 整批价格6，重量2；必须至少付2铁钱，其余可用交子 |
| 收费桥 | 每次进入扣1铁钱；移动前明确显示 |
| 步数 | 沿连接边每次移动1步，上限4；对话、查看、核对、兑换与付款不扣步 |
| 上路 | 货仓→收费桥→布铺→交付商行，共3步 |
| 下路 | 货仓→街巷→后巷→布铺→交付商行，共4步 |
| 交付 | 已成功购买布料，抵达商行后主动确认交付；重复提交无效 |

货仓内探索、走近柜台等是节点内部的演出，不增加图节点或扣行动。出仓后移动属于原有交易路线，仍扣步；“探索不扣步”指查看节点与当前节点内的探索，不代表跨节点免费。可预览远处地点，不可直接跳过去。

### 2. 这一关的故事

你带着介绍信来到罗记。阿禾领你整理货款时，发现柜底失而复得的旧交子。罗掌柜把它收了起来，让你们先替商行取一批布。

路上，你认识了阿禾：她对人和街道很熟，却不愿多谈那张纸。到了布铺，沈娘子没有照单交货，而是让新来的你核对布样、摸一摸受潮的布角，再亲手付账。

这件小事办完，你第一次在罗记账簿上留下自己的记录。临走前，阿禾主动让你陪她去看柜底的旧匣。她要查清的事情还没有答案，但你已经不只是一个来做工的陌生人。

本关的关系变化：陌生→能一起办事。旧票只留下一个问题，不在首关解释历史大事件或完成商号危机。

目标体验约15—25分钟，包含自选探索和思考；未经阅读计时与试玩验证。赶主线者应可明显缩短，不能用强制等待凑时长。

### 点击反馈

- 第一次点击可达相邻地点：显示路线与费用；再次确认后小人沿现有边移动，抵达再触发事件。途中锁定重复移动输入。
- 点击远处地点：只显示地点预览和规则，不移动、不扣步。
- 点击当前节点人物：小人走近后开启对白；节点内移动不扣步。
- 点击道具：打开清晰的近景查看；“收起”回地图，不推进别处剧情。
- 可选对象用统一轻提示，不做满屏闪烁；对话结束要回到地图操作。
- 阿禾跟随玩家，停步时站在侧后方，不挡路、不参与碰撞谜题。主动对话可让她转身；无需物理寻路造成卡死。

## 四、完整主线与可选对白

### S01｜雨后开门

触发：首次进入第一关。地图已显示罗记，小人在门前。只显示一段开场旁白，随后立即允许点击阿禾。

旁白：雨停了，门檐还在滴水。你把介绍信从衣襟里取出，信封的一角已经软了。

阿禾〔平常/探身〕：“找罗掌柜？”

玩家：“信上写的是这里。”

阿禾〔微笑〕：“那没走错。进来吧，门槛有些滑。”

【交互】点击阿禾旁的入口，小人进入后仓场景。无需长开场任务弹窗。

罗掌柜〔平静/合账簿〕：“信给我看看。”

玩家递信。罗掌柜看信，阿禾给你放了一碗水。

罗掌柜：“会看货单么？”

选项：

- “会，没独自办过买卖。”→罗掌柜：“那就先办一笔小的。”
- “认字。别的，得边做边学。”→阿禾〔微笑〕：“肯问就行，别跟钱袋较劲。”
- “你先给我看看。”→罗掌柜〔平静〕：“不急。先把手暖一暖。”

合流，罗掌柜：“布铺给我们留了一批青布。阿禾带你认路，你来核货、付账。”

阿禾：“先看货款。我去拿单子。”

【恢复操作】目标仅显示“到柜台准备货款”。可先查看店内对象，不强制逐个点击。

#### S01可选探索

柜台账簿：旁白“同一笔账改了两次，旧数划去，新数写在旁边。”阿禾〔平常〕：“错的别擦，划掉，旁边写清楚。省得过两天自己也不认。”再次查看只保留物件描述。

墙上挂钩：玩家：“空的这个挂什么？”阿禾〔微笑〕：“我的斗笠。昨日借出去了，还没还。”不产生收集任务。

热水碗：旁白“水已经不烫了。”阿禾：“再等会儿，可就只能洗手了。”只播一次，不延长喝水动画。

### S02｜柜底木匣

触发：点击钱袋准备取钱，先演出一枚松脱的钱滚到柜底。该钱仍属于仓库8铁钱，不额外增减资产。

阿禾〔认真/蹲下〕：“等一下，袋口没系好。”

【交互】点击柜底亮起的钱，小人靠近。近景里钱在外侧，木匣在内侧；点击钱即拾起，同时看到匣角。不要求精准找像素。

玩家：“这里还有个匣子。”

阿禾〔思索→担忧〕：“……能拿出来么？”

【交互】点击“托住匣底”；匣盖松开，露出旧交子。玩家可点押记查看，也可直接收起近景；不允许拿去花。

阿禾：“掌柜，你来看。”

罗掌柜〔为难/视线下移〕：“原来在这里。”

阿禾：“你上回说，大概同旧账纸一道收走了。”

罗掌柜：“是我记岔了。”

选项：

1. “先扶稳，匣底快散了。”
   - 设置 `oldNoteResponse=help`。
   - 阿禾〔平常〕：“你托着这边。我来合盖。”
   - 罗掌柜〔平静〕：“多谢。搁柜上吧。”
2. “这张交子，是谁留下的？”
   - 设置 `oldNoteResponse=ask`。
   - 罗掌柜〔为难〕：“以前的一笔账，还没查清。”
   - 阿禾〔认真〕：“那这次别再混进废纸里了。”
   - 罗掌柜：“不会。”
3. 把匣子放上柜台，等他们说。
   - 设置 `oldNoteResponse=wait`。
   - 阿禾〔平常〕：“你手上都是灰。”
   - 她递来一块布。罗掌柜收起木匣，没有再翻开。

合流：罗掌柜将匣子放进柜格，上锁。阿禾看了一眼锁，拿起货单。

阿禾〔平常〕：“先去取布。再晚些，沈娘子就要忙了。”

【完成】`oldNoteSeen=true`。旧票近景加入回看，不变成货币道具。后续准备面板不再重复演出。

### S03｜自己装钱袋

触发：点击柜台“准备货款”。

罗掌柜〔平静〕：“这里是八份铁钱。布钱六份，路上花的也从这里出。回来对账。”

阿禾〔认真〕：“钱袋只能承五格。你先试试。”

【实操】展示仓库8、拟携带铁钱、交子、5格负重。允许查看铁钱和交子外形；初次出发方案不强制填入参考解。

玩家尝试不兑换出发：预览8/5，不提交。阿禾〔微笑〕：“口子能扎上，背带可不答应。”原因栏：“超出3格，需先调整。”

首次打开兑换：

阿禾〔平常〕：“这批货款可以在出仓前办兑换。每办一次收一份，余下换成交子。”

玩家：“布铺肯收？”

阿禾〔认真〕：“肯。但至少要给她两份铁钱。她的条件记在货单上了。”

【实操】兑换X的加减有2—8边界；展示“投入X／手续费1／交子X−1／携铁钱8−X／出发负重”。2、8等合法预览可以看，但若后续会无解不得伪装成已验证可通关；玩家可主动求助。

【货单短面板】布料价格6，重量2，至少2铁钱；桥路3步、桥费1；巷路4步、免费；上限4步。不把关键规则藏进对白。

准备阶段所有更改为草稿，点“备好出发”才一次性提交兑换、手续费和出发资产；正式跨出第一条边前仍可回到草稿重配，不叠加手续费。

点击“备好出发”：

阿禾〔平常〕：“我认路，怎么走你来挑。”

地图同时展示桥和街巷费用，不用再弹章节说明。

【可选问话】

玩家：“那张旧交子，还能用么？”

阿禾〔思索〕：“我没打算拿它去买东西。”

玩家：“那为什么还留着？”

阿禾〔担忧〕：“有些事得看过上面的记号，才能继续查。等回来再说吧。”

此处不回答兑付真假，不引导玩家把旧票当可用资产。

### S04A｜桥上路线

触发：确认货仓→收费桥前显示“1步，1铁钱”。验证足额后一次性扣费、扣步、移动；到达播放。

守桥人〔平常〕：“往这边过，一份铁钱。”

阿禾〔平常〕：“来回都收。咱们这回过去就到布铺，不折回来。”

守桥人接过钱，挪开拦路木杆。地图数字已随移动正确变化，此处不再扣一次。

玩家：“你日日都走这里？”

阿禾〔微笑〕：“我没带货时，走下头。省下的钱还能买点东西。”

【恢复操作】可选点击桥边看水，或直接去布铺。

可选桥边：

旁白：昨夜落下的树叶积在桥墩边。阿禾把你往里侧让了让。

阿禾〔认真〕：“看归看，钱袋别探出去。”

选项“你掉过？”→阿禾〔微笑〕：“斗笠掉过。那回我追了半条街。”

选项“我拿稳了。”→阿禾〔平常〕：“好。新来的总要多问一句。”

此交互无随机掉钱、无隐藏奖励。之后前往布铺，沿边再扣1步。

### S04B｜街巷路线

触发：货仓→街巷，1步无费用。

阿禾〔微笑〕：“这头得多走一段。不过有檐，雨天好走。”

小人路过挂布架，阿禾停在旁边，不自动强制开启长对话。可点布架或继续后巷。

布架可选：

玩家：“这些颜色差得不多，怎么认？”

阿禾〔思索〕：“摊开看。折在里头的，和晒在外头的也未必一样。”

玩家：“你连布也会挑？”

阿禾〔微笑〕：“看别人挑过。待会儿沈娘子要问，你可别替我夸口。”

记录 `clothInspected=true`，只改变布铺一行对白，不自动完成核货。

阿禾可选对话：

玩家：“你在罗记多久了？”

阿禾〔平常〕：“三年。刚来那阵，送过一次货，回来才发现单子没让人收。”

玩家：“后来呢？”

阿禾〔无奈/用思索资源〕：“又跑了一趟。人都吃上饭了，我在门口等。”

选项“所以今天才让我拿单子？”→阿禾〔微笑〕：“嗯。总得有人提醒下一位。”

选项“掌柜扣你工钱了？”→阿禾〔平常〕：“没扣。让我第二天自己去补。”

【下一地点】街巷→后巷，再扣1步。

### S05｜后巷避水

触发：第一次抵达后巷。短旁白，不设置额外移动障碍。

旁白：晾布的竹竿伸出墙头，水滴落在青石边缘。阿禾走在外侧，把有檐的一边留给你。

阿禾〔平常〕：“前头左转就是布铺。”

【可选互动】点阿禾询问旧票；不问也可去布铺。

若 `oldNoteResponse=help`：阿禾先说：“方才多谢你托着。那匣底真要散了。”

若为ask/wait：玩家：“柜底那个匣子，你找过很久？”

阿禾〔思索〕：“找过。后来店里搬了几次东西，就更说不清在哪里了。”

玩家：“你认得那张纸？”

阿禾〔担忧〕：“上头有我爹做的记号。”

她看向布铺的方向，等挑担的人从巷口过去。

阿禾：“我只想先看看。你别在铺子里替我问人，好么？”

选项：

- “好，等你想说再说。”→`notePrivacy=promise`；阿禾〔平常〕：“嗯。走吧。”
- “若查账要帮忙，可以找我。”→`notePrivacy=promise`；阿禾〔微笑〕：“你先把今日这笔记清。我可记着这句话。”
- “我不懂，暂时不问了。”→`notePrivacy=neutral`；阿禾〔平常〕：“也好。”

之后后巷→布铺，再扣1步。此段信息在桥路线结尾可由阿禾补述，不强迫重玩才理解主线。

### S06｜布铺认人

触发：第一次进入布铺。地图保留，沈娘子底部立绘出现。

沈娘子〔平常/理布〕：“阿禾？这位是新来的？”

阿禾〔微笑〕：“掌柜让他来取布。我带个路。”

沈娘子〔微笑〕：“那货单给我，还是给他看？”

阿禾：“先给他吧。总不能我看、我拿、我付，他在旁边站着。”

沈娘子把三包布挪到柜台上。

沈娘子〔平常〕：“三家预订的，都放在这里。你核对自己的那包，别替别人带走了。”

【恢复操作】目标“对照货单找出罗记的布”。玩家可随时查看货单，不做记忆考试。包裹分别是灰布、青布、素布，标签和布色同时区分，不仅靠颜色。

### S07｜核布互动

触发：点击候选包裹打开近景，显示“看标签／展开布角／就是这包／放回”。不要求拖拽；可加拖拽但必须提供等效点击。

正确包：青布、罗记标签。货单显示相同布样与商号。

错误包一：灰布、陈记标签。

沈娘子〔微笑〕：“那包陈记已经付过定钱。你若替他带走，他待会儿可得来找我。”

### S08｜柜台付款

触发：核货后点击沈娘子“付布钱”。

沈娘子〔平常〕：“整批六份。至少两份铁钱，其余交子也收。”

玩家可问：“为什么要留两份铁钱？”

沈娘子〔平常〕：“下午送货的来取脚钱，我得给他备着。你们先前也是这样付的。”

这只是虚构商户的个人处境，不推广成宋代布商统一制度。

【实操】显示自持铁钱、交子、付款总额/6、至少2铁钱、支付后负重。加减上限≤实际余额且不超过订单所需；按钮与提交逻辑都校验。初始不自动填最佳解。

玩家可以关掉面板继续查看布，但布铺不会重新播放开场。关面板不扣钱，不记撤销，草稿可保留；切换关卡或重试不能带走草稿。

确认合法付款后一次性扣钱、增加布料2格、记账；同一包只能买一次。

沈娘子〔微笑/扎布〕：“数目对了。”

她把布包转过来，提手朝向你。阿禾伸手扶了一下，很快又松开。

阿禾〔平常〕：“提得住么？”

沈娘子〔认真〕：“湿的那角，回去记得摊开。”

罗掌柜〔平静〕：“回来了。放这边。”

【交互】点击货台放布的视觉预演，展示“布料一批／付款6／路费{实际费用}／余款{实际余额}”。确认交付前布仍在玩家资产中，不能因拖放演出提前移除。

罗掌柜：“货看过了？”

若 `dampCornerSeen=true`：

玩家：“青布没错。外角受了潮，里面干的，得先摊开。”

罗掌柜〔满意〕：“好，放窗边。我等会儿来收。”

若 `dampCornerSeen=false`：

玩家：“沈娘子说，外角有些潮，别直接上架。”

罗掌柜〔平静〕：“那就在这儿打开看看。”

【补充交互】点“展开检查”，布角摊开，内层干燥。罗掌柜：“没事，晾一晾。下回在铺里看清楚，省得抱回来再拆。”设置 `clothAcknowledged=true`。此为多一道操作，无罚款或坏结局；存档恢复必须仍能完成。

【确认交付】原子提交移除货物、完成任务、记实际账目；余款仅记录结算，不新增跨关资产。成功标记后继续S10，不让后台完成状态直接跳过结尾。

罗掌柜〔平静/推账簿〕：“这笔你记。”

【交互】以实际操作自动生成待记账行，玩家点选想补充的内容。财务数值不可随便改成假账。

选项一“先把钱和货记清楚”→`reportStyle=ledger`。

玩家：“货款六份，路费{实际费用}，余款{实际余额}。布已送到。”

罗掌柜〔满意〕：“嗯，写得清楚。”

选项二“再补一句布角受潮，已摊开”→`reportStyle=detail`。

罗掌柜〔满意〕：“这个也记。换个人收货，就知道不用再拆一遍。”

阿禾〔微笑〕：“你记着了，我就不用再喊一声。”

选项三“问掌柜，这样付钱还可以怎么安排？”→`reportStyle=question`。

罗掌柜〔平静〕：“有别的付法。先把你这一趟的账留下，想换一条路，回头再算。”

这只是开启结算对比入口，不自动列出全部答案。

按实际路线补一句：

- 经过桥：阿禾〔平常〕：“这回走桥。你给我看的路线，确实少一段。”
- 经过下巷：阿禾〔微笑〕：“后巷有点绕，好在一趟就办齐了。”

罗掌柜合上账簿：“先歇会儿。我去前头收货。”

### S10｜匣子留下的事

触发：交付后罗掌柜走到货架，阿禾留在货台边。只展开这一段收束，不自动开始第二关。

若桥路线未听过父亲线索，阿禾〔思索〕：“早上那张纸，上面有我爹做的记号。我找了它很久。”

若已听过，阿禾〔平常〕：“早上那个匣子，掌柜答应让我再看看。”

若 `notePrivacy=promise` 或 `oldNoteResponse=help`：

阿禾〔微笑→思索〕：“一会儿我想再看看那张纸。你愿意陪我么？”

否则：

玩家可选“你还想查那张交子？”→阿禾：“嗯。我想先认清上面的字。”

玩家可选“今日的账，我记好了”→阿禾〔平常〕：“我看见了。我也有一笔旧账，想重新看看。”

旁白：门口又响起车轮声。你把账簿上的墨迹晾干，将笔搁回原处。柜格还锁着，钥匙在罗掌柜腰间。

## 五、非法操作、求助与重玩文本

所有拦截先显示具体系统原因；人物只在首次相关错误时补一句，不每次抢话。非法操作不消耗资源、步数、撤销记录，不推进剧情标志。

| 情境 | 短反馈 | 可选角色回应 |
|---|---|---|
| 数量达到拥有上限 | 加号禁用，显示实际持有量 | 无 |
| 铁钱不足2 | 布铺至少收2铁钱 | 沈娘子〔认真〕：“铁钱得留两份给我，刚才说好的。” |

| 总付款超过6 | 超出{差额}，请调整 | 沈娘子〔微笑〕：“这包可没这么贵。” |
| 超重 | 操作后负重{load}/5 | 阿禾〔认真〕：“先看拿走多少，再看添进多少。” |
| 桥费不足 | 过桥需1铁钱 | 阿禾〔思索〕：“先别过去，看看另一条路。” |
| 非相邻地点 | 只显示预览，不移动 | 无 |

| 重复购买 | 这批布已买下 | 沈娘子：“都给你扎好了，别落下。” |
| 未买布到商行 | 还没有可交付的布 | 罗掌柜：“货还没到？先把这一趟办完。” |
| 正确抵达第4步 | 当前节点仍可交易和交付 | 不误报失败 |

不强制实现全局死局求解器；若没有验证过的求解器，不能武断弹“此局无解”。明显资源不足可以提示证据；玩家始终能撤销或整关重试。

主动求助三级：

1. 阿禾〔认真〕：“布铺要留两份铁钱，钱袋还得装得下。先看这两件。”
2. 阿禾〔思索〕：“走桥还要再留一份铁钱。绕巷子省钱，但多一段路。”
3. 再次主动确认“看一组办法”：展示参考方案“投入5铁钱，得4交子，带3铁钱出门；付2铁钱＋4交子。走桥花3步、余款0；走巷花4步、余1铁钱”。不自动执行。

首次重玩可选“保留剧情”“略过已读剧情”。略过只跳已读对白，仍完成必要状态初始化、玩家选择和交易；不默选会影响后文的分支。重新开始清空本局资源、事件、选项、历史栈，不清掉已读记录；已读记录不等于事件已执行。

撤销只针对已提交游戏行动和有状态后果的剧情选择。打开面板、加减草稿、查看道具不占历史。撤销行动恢复完整资金、货物、位置、步数、交易、剧情标志和待播事件；路线对白与当前位置匹配。独立已读记录可以保留，不能用它阻断恢复后的必要剧情。终局完成后的重玩走新会话，不在已发布结算上倒扣资产。
