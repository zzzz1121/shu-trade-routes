# 临时视觉规范 V0.1

此规范只用于可玩原型，不代表最终美术定稿。手机竖屏、二维平面桌游布局，不使用背景整图或 AI 插画。

## 视觉令牌

集中定义：miniapp/styles/tokens.css；组件样式：miniapp/styles/game.css。两端直接复用。

正文使用系统中文无衬线字体，标题和地图符号暂用系统衬线；不分发字体文件。正文 15px，说明 13px，页面标题 24px，首页标题 42px。大范围圆角 16px，按钮 10px。避免粗黑描边、渐变、霓虹和装饰堆砌。

## 布局与交互

内容最大宽度 480px，左右间距 20px；≤360px 时缩到 12px。地图节点按配置百分比定位，路线动态绘制。地图布局要求道路水平或垂直，后续任意角度道路需扩展展示层。

所在节点蓝底，可达节点金边；点击非法节点会给出理由，不扣步数。颜色以外也有所在地可访问名称与文字反馈。按钮最小触控目标 44px；动态操作结果使用浏览器 role=status。地图顶部说明避免与交付点遮挡。

主界面从上到下：关卡目标 → 步数/负重 → 路网 → 钱袋 → 反馈 → 所在位置可执行操作 → 撤销/重试/规则。兑换/购买前显示预览，动作需明确点击确认。较小屏幕允许自然纵向滚动。

## 正式替换

正式图片放 assets/final/；将节点字符和钱币占位换成独立图标，保留数字、价格、路线和交互区域的动态性。小程序导入根为 miniapp/，将需要发布的素材复制到 miniapp/assets/final/，页面使用相对路径引用。不要把临时规范固化为最终画风。真机仍需验证字体回退、CSS 变量和安全区域。
