# 《蜀地钱路》视觉规范 V0.1 · 参考图场景版

## 视觉依据

以用户最新提供的地图截图为构图依据，原图保存在 `docs/references/approved-game-ui.png`。调用内置 imagegen 编辑原图，去除文字、白色文字底板、圆形地点标记和白色路线虚线，保留建筑、石桥、河道、道路地面、树木、岩石、围墙和布匹陈设。生成结果为 `miniapp/assets/approved/town-atlas.png`。approved 目录表示参考方向已确认，不代表生成结果已获最终美术验收。

地图保留参考图的现代数字插画、斜俯视中式木构建筑、灰蓝屋顶、柔和投影和青绿水岸。图像不是逐像素复制，局部植被、瓦片、货物细节有生成式变化。使用原始截图比例 634:522，不拉伸成正方形，不加入额外氛围装饰。

## 实现边界与分层

本版采用场景图集分区方案：同一张无文字场景图，按 `miniapp/ui/scene.js` 的六个建筑区域与剩余地形区域分别裁切显示。地形层、建筑区域层、代码道路层、交互节点层及页面 UI 分开。各分区拼合完整构图，不在 PNG 上烘焙动态文字或按钮。

这不是六张已抠图的透明建筑精灵：当前矩形建筑区仍包含周边地面，暂不支持随意移动建筑而不修补地形。未来需要重新布置地图时，应先补充无建筑底图与独立透明建筑。替换素材和展示坐标不需要修改规则引擎；分区坐标不能作为路网或交易判定。

动态白色虚线根据原关卡六条边绘制：货仓—收费桥—布铺—交付商行；货仓—街巷—后巷—布铺—交付商行。原参考图未清晰画出的布铺至交付商行连接也由代码补齐。道路地面本身属于插画。

## 设计令牌

集中在 `miniapp/styles/tokens.css`，组件样式在 `miniapp/styles/game.css`；浏览器和小程序共用。地图构图比例及锚点集中在 `miniapp/ui/scene.js`。

## 固定屏和操作区

优先验收375×812、390×844、430×932。整页固定于视口，顶部任务与步数、中央等比例地图、底部钱袋与交易面板共同显示，不上下滑动。规则说明使用三页弹层。保留安全区域 padding；真实小程序安全区域仍待真机验证。

底部资源行展示铁钱、交子、布料及五格负重；初始8铁钱属于货仓，标注「待装载8/5」，不会允许超重出发。兑换前预览、兑换后确认出发、到店混合支付及交付都由现有状态驱动。不同操作复用底部空间，不添加静态装饰按钮。

## 仍需验收

地图图集生成细节、资源图标与场景笔触的一致性、原生图片重复引用的内存表现，以及小红书包体与真机渲染。当前通过的是浏览器测试，没有声称官方开发者工具验证通过。

## 界面文案精简

移除地图下方教学小字、撤销旁重复说明、首页底部重复文案、默认备钱提醒及规则中的历史币值免责声明。保留操作相关的手续费、支付/负重预览、错误原因与资源变化。无反馈内容时收起反馈行，不预留空行。历史背景说明仅留在项目文档中。

## 上下场景延展

新增 `miniapp/assets/approved/town-extended.png`，由内置 imagegen 对中央图集向上下扩图。独立 scene-continuation 底层填满任务区与钱袋区之间的弹性高度，保留原中央图集的634:522比例和六个节点锚点。中央图集的上下边缘以22px蒙版过渡到延展地形；文字、路线和点击层不参与蒙版。地形进入底部面板后方，避免留白带。全场景继续使用0.62饱和度令牌。

`tests/terrain-extension.cjs` 验证375×812、390×844、430×932上的地形覆盖、图片加载、图集比例和点击穿透；`tests/fixed-screen.cjs` 继续验证两条路线及单屏操作。

## 底部面板两侧景物

游戏态新增 panel-terrain 底层，复用现有延展图的下方景物，覆盖操作面板两侧及底部安全区域。保持图片原比例和0.62饱和度；地图末端以32px过渡衔接到底层。该层不接收点击，不出现在首页与结算页。

## V2.0 交互与多关卡补充（现行）

第一关沿用原有构图及延展。第二至六关采用无建筑地形底图、透明建筑图集、配置道路/节点、页面 UI 四层。各关节点与边由关卡配置决定，建筑脚点依节点锚点布置；5节点图使用较大建筑，7节点图缩小建筑以保持道路与点击区可见。新增建筑滤镜 `--modular-saturation:.55`；其余插画保持 `.62`。

仓库阶段：随身负重为0，单独展示“仓库铁钱”和“拟装载”。不再把仓库8铁钱计入人物负重。货物单列成紧凑物品行；交易面板保留两个独立金额选择器，按钮44px。旅行态面板收缩，不空占交易空间。

点击任意地点可看公开条件；相邻且可支付时才显示确认移动。规则弹层根据该关交易数量分页。教学采用非阻塞短卡，页面下方操作仍可使用；跳过、重放序幕、三级提示不耗步。错误信息使用具体金额/重量差额，保留必要反馈，不恢复常驻说明小字。

票据共用现有位图，加甲/乙/官代码印记与文字，避免只靠颜色区分。颜色在 tokens.css 集中维护。没有新增 Emoji、SVG 建筑、人物占位头像或大幅人物插画。

与参考图主要差异：第一关仍使用参考构图图集；后五关为模块布局，尚未达到参考图各商铺独有陈设的细节。当前通用商铺会复用，缺正式人物和独立票面。资源替换只影响场景/展示配置，不影响价格、道路和胜利判定。
