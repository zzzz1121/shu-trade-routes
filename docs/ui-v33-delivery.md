## 结构与设计规范

- 共享视觉层：`miniapp/styles/ui-v33.css`，由浏览器、小程序共同引用，并纳入静态构建。旧版故事样式保留基础职责，V3.3 在命名明确的公共层覆盖。
- 配色：纸底 `#f2eddf`、纸面 `#fffaf0`、字色 `#344039`、灰绿 `#6d8072`、浅蓝 `#d5e2df`、主按钮柔棕 `#806b50`、细线 `#d8cfbc`。未加藤蔓、流苏、木牌边框、铜钱装饰。
- 字体：标题及对白用现有系统宋体／衬线回退，数字和操作采用系统无衬线。标题约 28–32px，正文对白 17px，功能正文 14–16px，次级标签 12px。交易数量突出至 21px。
- 统一状态：纸面次按钮、柔棕主按钮、禁用变淡、明确键盘焦点；主要操作及交易增减触区约 44px。章节锁定使用低饱和和状态文字同时表达。
- 布局：竖屏容器最大 480px，安全区使用 `env(safe-area-inset-*)`，正文与表单按可用空间排布，手记／账簿可滚动。地图标签缩小，背景和实际按钮分层。
- 演出：界面反馈 180ms；沿用 480ms 行走与 80ms 落点后提交；自动对白按句长等待约 1.8–6 秒。尊重系统减少动态效果偏好。
- `miniapp/ui/story-view.js` 提供共用手记数据与交易状态；`web/story-ui.js` 和原生页面只呈现。规则引擎、道路、费用和关卡数据未修改。

## 交互修正

1. 新开幕是可保存的展示状态，刷新仍回首页，继续可回到开幕；不会提前扣款、跳过 S01 或创建额外资产。
2. 自动播放位于共用演出控制器，只读对白；分支、道具确认、钱货提交均等待玩家操作。回看和声音面板暂停推进，切后台及销毁取消定时器。
3. 对白时屏蔽底层地图／交易控件，浏览器加 `inert` 防止键盘和鼠标误触；原生通过遮罩和显示状态屏蔽。
4. 布铺可查看商路、从当前节点重新进入，进出不耗步、不改资产。买好布后自动恢复地图，不滞留店内。
5. 气泡不再截获底下节点点击，已实测后巷可达。
6. 第一关撤销优先恢复最近一次钱货／移动提交及对应剧情快照，跳过夹在其后的纯对白快照，避免只能撤回一句话。没有钱货／移动历史时仍可恢复最近剧情选择。正式结束后不撤销已完成章节。
7. 公共委托面板使用实际当前关标题和目标，后五关不再冒用首关摘要。交子史话移入规则页，保留功能可达性。

## 正式素材及验收边界

- 本轮没有重画地图或整套人物，也没有重写人物关系。首页／结算复用已确认的商镇素材，角色仍用固定表情图集。
- 布铺室内暂复用统一画风的后仓室内图，并以独立店招、沈娘子和真实交易组件组合。正式布铺背景是后续素材缺口；替换入口为 `shopScene` 及原生 `shop-stage`，不涉及规则层。
- 配乐和音效继续使用现有原创程序合成原型文件，非真实古琴或笛子录音。本轮保留音乐、音效、环境独立设置及音量接口；自动测试确认播放链路，音乐听感仍交由玩家验收。
- 小程序已同步共用状态及页面结构，并通过 Node 适配器与模板检查；本机没有运行官方小程序开发工具，不能声称已完成设备端视觉验收。
- 视觉验收以本次真实截图及可玩预览为准。保留了既有素材造型，因此不会与参考图中的新人物及新背景逐像素一致。
