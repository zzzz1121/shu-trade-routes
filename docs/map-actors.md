# 第一关地图小人

使用 imagegen 生成的透明 PNG，资源和生成提示词位于 `miniapp/assets/characters/map-v4/`。玩家为灰蓝衣行商，阿禾为青绿衣伙伴，身份分开。

每套图集三列四行：列为站立、左步、右步；行为朝下、朝上、朝右、朝左。玩家单帧宽高比约 1.3976，阿禾单帧为正方形，显示容器分别保留原比例。没有缩改原始位图。

`miniapp/ui/map-actors.js` 统一输出资源路径和方向帧。浏览器与小程序共用，坐标仍来自原道路。480ms 移动中按方向切换帧，阿禾沿同一路线滞后跟随；到达后回到站立帧，仍由原控制器确认扣步和收费。只接入第一关。没有改关卡规则、道路或费用。

验证：单元测试覆盖方向帧和两套资源；`node tests/immersion-browser.cjs` 在 375、390、430 宽度检查延迟提交、重复点击、到达后对话、撤销和切后台取消。小程序经过适配器测试，尚未官方编译与真机验收。当前图集为生成美术，仍可继续人工修帧。
