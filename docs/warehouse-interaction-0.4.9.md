# 0.4.9 后仓场景交互

针对四个物件在底部排列成菜单的问题，仅调整后仓探索的呈现，不改道路、费用、剧情分支或规则引擎。

- 进店对白结束后，进入罗记柜台近景。钱袋、账簿、水碗在台上，挂钩在墙上；透明热区覆盖实际物件。鼠标悬停/键盘聚焦显示名称，触屏直接点物件。主目标提示钱袋，其他物件可选，不要求全点。
- 钱袋进入拾钱剧情；柜底铁钱出现后可拾取，再发现旧匣。木匣被打开前不再提供查看旧票的按钮。准备货款时自然回到原地图。
- 底部不再显示这四个物件按钮，去掉重复账簿工具。柜台阶段的资产栏叫“货款明细”；交易记录仍在“更多 → 本趟账簿”，与桌上旧账簿的观察对白区分。
- 浏览器与小程序共用 `storyRoom` 和 `roomObjects` 展示数据，仍发出已有 `object:*` 动作；存档可直接续接，不迁移或清空进度。
- 新背景为 imagegen 根据已确认地图生成的后仓内景，保存在 `miniapp/assets/chapters/warehouse-interior.png`，生成提示词同目录保存。图片失败时使用可点击的简化场景，不阻塞剧情。

验证：103 项单元测试通过；V4 两条完整路线在 375×812、390×844、430×932 的浏览器回归通过；专门的后仓测试在 375×667、390×844、430×932 检查四个物件热区不重叠且至少 44px、可选观察不修改钱货或步数、刷新续接、拾钱/旧匣与回地图。生成背景接入后重新执行后仓点击测试与构建。

截图：`outputs/warehouse-exploration-375.png`、`warehouse-exploration-390.png`、`warehouse-exploration-430.png`。小程序适配器和模板结构检查通过，仍未进行官方真机验收。

修复后续指引：当前必要物件（钱袋、掉落铁钱、旧匣）常显动作标签；铁钱扩大、提高对比并增加静态定位圈。标签本身可点，避免下一步只有一个难以发现的小点。三种尺寸回归额外检查标签不被近景裁切，并以点击标签走通拾钱、发现旧匣及回地图。新增 `outputs/warehouse-coin-390.png` 和 `warehouse-box-390.png`。
