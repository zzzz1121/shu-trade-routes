# 0.4.7：只精做第一关的走动与轻量声音

本轮仅在「布匹之约」开启小人、路径演出、环境音与交易/关卡声音。第二至六关继续使用原来的即时移动，不接入关卡演出；首页和菜单的声音设置属于共用设施。价格、负重、桥费、行动上限、通关条件与现有短对白不变，也未扩写正式剧情。

## 第一关的走动

- 使用可替换的简化行商标记：草帽、绿色衣袍、褐色背包与两条腿。暂未使用正式人物序列帧。
- 只沿已确认的相邻道路移动。第一关沿既有弯道采样，反向行走复用同一条路线；不做自动寻路。
- 行走 480ms，余弦缓动；脚步交替、身体轻微起伏。到达后留 80ms 落点反馈，总时长约 560ms。启用系统减少动态效果时缩短为 120ms 并关闭起伏。
- 当前整段路径以低饱和褐金色细线强调，没有粒子、光效或拖尾。行走时只锁操作，不把地图文字淡掉。
- 到达前不改变位置、资金、货物、行动次数或剧情。落点后才调用原控制器提交一次移动、扣桥费、刷新交互、弹教学或进入失败状态。
- 行走途中连点无效。后台/离页取消尚未提交的移动；计时器失效后不会偷偷补交。已完成的移动仍走原撤销逻辑。

`miniapp/ui/experience.js` 管理临时演出；`scene.js` 输出道路点和距离采样；前端只接收位置和 walking/arriving 状态。正式小人可替换 `traveler` 的视觉结构，不需修改引擎或移动规则。浏览器和原生适配器显式传 `levels:['l01']`；后续逐关验收后再开放其他章节。

第一关所有相关反馈均已接入。换票、兑付和出售虽可复用交易接口，但本轮没有改动其他关卡的演出。解锁只在解锁状态真正变化时触发，重玩第一关不重复播放。

**正式采样资源：0 个。临时合成资源：18 个。** 所有 WAV 均由项目内 `scripts/generate-sounds.js` 确定性生成，没有使用第三方下载或未经授权的录音。环境是低通噪声与稀疏敲碰的近似，纸张是短促噪声，钱币是低音量非整数泛音；并非真实市集、河水或硬币现场录音。文件均为 22050Hz、单声道、16-bit PCM，环境片段 8 秒带淡入淡出。

素材在 `miniapp/assets/audio/`，统一名称/文件/相对增益/冷却在 `miniapp/ui/sound-catalog.js`。替换正式音频只需改清单或同名文件，不改调用方。运行 `npm run sounds:build` 可复现这些临时文件。

## 统一管理与设置

- 首页「声音」或游戏菜单「声音设置」：操作音效和环境氛围分别开关，总音量 0—100%，本机保存。
- `Sound.create(...).configure({effectsEnabled,ambienceEnabled,volume,effectsVolume,ambienceVolume})`；后三者为 0—1。
- `setVolume(value, 'master'|'effects'|'ambience')` 给后续设置页使用。错误数值忽略，越界数值钳制。
- 同类声音有 85—700ms 冷却；待播队列最多 16 项，每次序列最多 6 个；后端最多 4 个同时音效，另有最多 3 层环境。快速点击不会无限叠加。
- 对白压低环境，离开地图淡出环境；关闭音效清理待播声音。新行走清理上一笔操作尚未播放的延迟声音。
- 浏览器在首次真实操作时创建/恢复 WebAudio；首屏加载不自动响。窗口隐藏时暂停上下文并清理音效，回来只恢复允许的环境。
- 原生层适配 `createInnerAudioContext` 并进行能力检测，音频不可用/失败时静默降级，不影响交易和移动。遵循系统静音，后台释放资源。
