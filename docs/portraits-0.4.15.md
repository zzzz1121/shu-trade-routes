# 四位角色立绘重做 · 0.4.15

## 改动

阿禾、罗掌柜、许掌柜、沈娘子均重新生成：每人普通、微笑、思考、疑惑、担忧、认真六张，共 24 张 1024×1536 透明 PNG。保留各人的脸型、发型、服装与手持物，以同一基准图制作表情差分，统一手绘水彩／铅笔质感。来源及完整提示词位于 `miniapp/assets/characters/v35/prompts.json`，使用内置 image_gen。

取消从多人图集中裁切立绘，改为按人物 ID 和表情直接加载独立文件；不再存在相邻格人物内容。正文对白、开场、交易、回看与提示共同使用新资源。正式对白的角色舞台独立于对白框，统一人物比例、居中位置和透明留边。未知表情回落普通表情；旁白不新增人物。地图行走小人与剧情、交易规则未改动。

此次差分保持站姿与手持物稳定，以眉眼、嘴角表现情绪；原有 `pose` 字段保留，便于后续加入动作演出。旧资源保留用于历史版本，不再被角色渲染器引用。
