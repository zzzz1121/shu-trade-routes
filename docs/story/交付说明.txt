《灯下旧账》本轮交付说明

内容：
1. 灯下旧账-完整台本.txt：序章、六章、三个结尾，六处选择，包含全部分支回应、条件回响和中文表情标记。台词正文及旁白共7608个汉字（含互斥分支，不含标题与演出标记）；不是每次游玩都会读到全部文本。
2. manuscript-source.txt：逐行对白源稿。scripts/build-story-concept.py 将它与分支定义生成 web/concept/story.json 和可读台本；修改后运行 npm run build:story。
3. story-bible.json：人物口吻、动机、时间线、章节任务卡、分支变量、历史来源和美术缺口。
4. visual-plan.txt：首页、对白、选择的视觉方向与自审。
5. web/concept/index.html：可点击视觉样机。入口 http://127.0.0.1:4173/web/concept/index.html 。顶部可切换首页、对话、选项、台本。对话页展示第五章雨夜片段；选项页展示第六章去留选择，属于分别审阅的样稿，不代表两幕在故事中直接相连。
6. web/concept/board.html：三屏并排预览；outputs/story-design-board.png 为截图。

方向：
人物是与玩家各有主张的同行者。约80%阅读与对话、20%短委托是设计目标，尚未实际计时。六关只标记为剧情中的可选短委托，尚未改成新的游戏主流程。默认不强制恋爱，也不按追索欠款与否惩罚玩家的关系结局。

史实与虚构：
人物、商铺、雨后货期、资金缺口、协商方式均属虚构。历史只作交子背景；官方发行放在多年以后，不由游戏人物引起。来源在 story-bible.json；没有把游戏的整数费用写成史实。
