## 在 VS Code 运行

在本项目目录打开终端：

```sh
sh scripts/dev.sh
```

浏览器访问 **http://127.0.0.1:4173/**。也可在 VS Code「终端 → 运行任务」选择「试玩蜀地钱路」。如果提示端口占用，已有试玩服务通常正在运行，直接打开地址。

另一台电脑需要 Node.js 18+。有 Node 的环境也可执行 `npm start`。游戏没有生产依赖，启动不需要安装游戏引擎或构建框架。

```sh
git clone https://github.com/zzzz1121/shu-trade-routes.git
cd shu-trade-routes
npm start
```

工作前 `git pull --ff-only`，完成修改后提交并推送；请勿把个人 AppID、开发者工具私有配置或令牌提交。GitHub 同步代码与素材，**不跨电脑同步游玩进度**。

底部不再显示独立工具栏：步数旁撤销，当前操作面板点“问阿禾”获取提示；右上角菜单可查看规则、重听委托、重新启程或选择章节。

点击建筑或地点牌查看条件，再确认移动。交易货币分别调节；确认前预览余额与负重。只有移动消耗步数。所有非法操作不改变状态；死局可撤销或重试。剧情和教学可跳过，主动提示分三级。

通关按顺序解锁，重玩默认跳过教学；本机保存已通关章节、教程记录、最近章节与当前局面。刷新统一回首页，点击「继续行程」恢复资金、位置、对白与撤销历史；选择章节重新开始则创建新局面。结算保留实际路线、采购顺序、货币支付、费用与余额。

## 小红书开发者工具

1. 安装官方工具，使用自己的开发权限与真实 AppID。
2. 以 `miniapp/` 为小程序源码目录导入，项目配置由实际工具创建。
3. 入口 `app.json` → `pages/index/index`；页面使用 `.js/.json/.xhsml/.css`，存储使用 `xhs.getStorageSync/setStorageSync` 官方示例签名。
4. 工具中编译并进行设备预览，重点检查模板表达式、CSS 变量/遮罩/clip-path、图片布局、安全区和本地存储。

**当前没有 AppID、官方工具编译或真机结果。** Native adapter 测试是 Node 中的 Page/setData 模拟，不是平台测试。素材尚未做发布级优化，完整 `miniapp/assets` 约 33 MiB（含前期未使用生成素材）；平台包体、类目和准入条件仍待确认，不能据此直接发布。

## 测试

```sh
npm test
npm run build:web
```

`npm test` 只需 Node 标准库，覆盖六关规则、限定组合枚举、可达状态不变量、死局与撤销、教程、章节进度、原生页面适配器和场景映射。

浏览器测试使用 Playwright（本次实际版本 1.62.1）和 Chrome。正常 Node/npm 环境可安装测试依赖后运行：

```sh
npm install --no-save playwright@1.62.1
npm run test:browser
npm run test:layout
npm run test:narrative
npm run test:journey
```

需要本地服务正在运行，并安装 Chrome。可用 `BROWSER_CHANNEL=chromium` 改用已安装的 Playwright Chromium。`BASE_URL` 可替换规则/关卡浏览器测试的入口。截图输出到 `outputs/`。

`npm run build:web` 将同一套源码与运行素材复制到 `dist/`，不执行发布。

## 结构和扩展

- `miniapp/core/level.js`：六关资源、路网、商户、目标、剧情与提示配置。
- `miniapp/core/engine.js`：纯规则转换、原子交易、有限状态搜索、会话快照。
- `miniapp/core/controller.js` / `presenter.js`：共用交互状态与数据展示；页面不另写交易规则。
- `miniapp/ui/scene.js`：地图图集区域和道路布局；`miniapp/styles/`：共用视觉令牌与组件样式。
- `miniapp/pages/index/`：小红书适配；`web/`：浏览器适配。
- `miniapp/assets/approved/`：第一关原有地图；`miniapp/assets/v2/`：新生成的透明建筑/货物图集和无建筑地形。

详见 `docs/v2-implementation.md`、`docs/visual-spec.md`、`docs/asset-manifest.md`、`docs/test-report.md`。用户提供的策划原文存于 `docs/game-design-v2.md`，存在冲突时以本次确认的实施范围和视觉偏好为准。
